== Description ==

An independent classic theme for small brands and creative studios. Build an editable portfolio homepage from native Pages, Menus, Customizer settings and Widgets.

== Installation ==

Upload and activate FastStudio White. Assign menus, choose a static homepage, select project Pages in Customize, and add studio copy in Widgets.
