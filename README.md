# FastStudio White

An independent WordPress Classic Theme for small brands, creative studios, and personal portfolios.

## Install

Upload the `faststudio-white` folder as a theme and activate it. No parent theme or business plugin is required. This is a new theme package; activation does not import or change site content.

## Build a studio homepage

1. Under Settings > Reading, choose a static Home page and an optional Posts page.
2. Under Appearance > Menus, assign the main and footer menus.
3. Under Appearance > Customize > FastStudio White: Homepage, set the introduction and choose up to three existing project Pages.
4. Edit each project in Pages. The title, excerpt, featured image, and page body remain normal WordPress content.
5. Add service, studio, and contact copy in the named Widget Areas. Configure footer content in Widgets; the footer has no forced platform or theme credit.

The theme uses native Menus, Customizer settings, Pages, Posts, and Widgets. It contains no page builder, remote fonts, tracking, forms service, or commerce features. The color appearance can be set to dark in the Customizer; White is the series name and the default canvas is light.
